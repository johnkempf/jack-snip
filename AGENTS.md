# Working with Tiger Snip

## Running the app

- Do not start Tiger Snip in tray mode (`--tray`). The user cannot reliably open it from the tray.
- You may launch the app and perform any testing needed for the task. After testing, fully quit every app instance you launched so the user can open it themselves.
- Use the app's **Exit** command to quit. Closing the editor window only hides the app in the tray and does not count as quitting. Verify that the process has exited.
- Leave the app fully closed when finishing a task. Do not automatically restart it after a build or fix unless the user explicitly asks you to leave it open.
